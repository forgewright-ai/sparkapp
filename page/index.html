      what this is
      
    
      What this page can do is what your shell can do: every button is a
      spark verb run on the box, and every card is what
      spark check, spark stats, spark serve
      and spark bench print. The page never runs a command you did
      not click.
      
    
      The palette menu in the header changes this browser only; the theme
      picker under config runs spark theme on the box.
      
    
      The FORGE knows two roles. The user token talks to the ember and
      shapes who it is; the admin token is the whole box.
      
    
      API health:  (no token needed; everything
      else under /api/ takes your token as a cookie or bearer).
